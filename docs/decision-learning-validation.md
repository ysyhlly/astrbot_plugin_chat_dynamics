## 训练与验收优化验证

随后完成请求级 Wilson 错误上界、完整目标集合评估、独立验证分区、最佳检查点及早停、每轮每样本最多三次的平衡抽样、随机种子配置与划分报告。近重复候选检索保持精确判定；纯人设快照与聊天连续段分域，防止相同人设连接不同群的聊天样本。含对话信息的人设快照仍按聊天规则保守分组。

完整回归 2831 passed、3 skipped；之后补标提供商重新解析及纯人设分组修正分别有定向回归，最新数据集/服务/评估/注册表联合检查 48 passed、2 skipped。旧报告没有新增证据时不能直接晋升。

目标 RTX 3060 上隔离合成烟测：72 条、seed 73、3 轮共 27 步，微批量 4，峰值显存约 6.10 GiB。训练/验证/校准/测试分别为 36/12/12/12 条，分组数 6/2/2/2。验证损失 0.548936 → 0.512938 → 0.479095，最佳检查点为第 3 轮；10 个模型产物文件校验通过。每个校准桶只有 2 个请求，多个目标候选未虚增证据，所有接管阈值保持禁用。集合评估识别出 1 个无目标却回复的组合错误；晋升返回 400，线上激活模型仍为空。该烟测不属于真实质量验收。

补标器增加错误类型诊断和指数退避，避免宿主启动阶段即时失败耗尽预算。历史教师不存在时，只重新解析原会话当前提供商并保存实际模型来源；不能解析则保留重试，不生成伪标签。

最终已覆盖服务准备后的两段 JSON 人设格式及空人设卡，数据集回归 23 passed。目标机最新只读报告：6540 条已标注样本、5 个会话、20 个分组，其中 108 条纯人设样本已正确独立分组；最大组仍有 6388 条。最终训练/验证/校准/测试为 66/56/18/6400 条，对应 11/3/3/3 组，报告计算约 7.48 秒。可形成四分区，但分布明显偏斜且校准仅 3 组，远不足以证明可靠接管。本轮没有运行真实数据训练，也没有晋升模型；合成 GPU 训练只验证管线。
