# 群间学习原生接入（v1）

本候选版与独立插件「群间学习」对接；这是新的能力契约，不恢复历史 v1.7 的发布文件或学生训练。

在人格回复主链捕获观察、最终决策、等待补充、生成/发送结果和已发送文本。通过公开注册表发现当前实例，回调仅入队；主回复路径不等待分析模型或 SQLite。

审批后的上下文进入本轮决策请求及原生 Agent 的回复 JSON。接话阈值增量仅替换现有 `join_floor` 输入，显式呼叫、对象判定、成员停止和发送边界仍执行原有规则。

学习内容与策略在回合开始固定，回合检查会在伙伴重载、停用、回滚或版本变化时拒绝受旧增量影响的结果。未安装或未启用该能力时保持原有行为。群间学习单独管理范围、模型、审查方式、数据与回滚。

完整协议和使用方式见群间学习安装包中的 README 与 docs/contract.md。Chat Dynamics 注册表卡片显示接口存在状态，不能代替业务效果验收。
